## 🚀 Project Overview: Learning Pandas Basics

I am currently learning the fundamentals of data manipulation using the **Pandas** library in Python. This repository tracks my progress as I practice core data engineering concepts.

### 📚 Key Topics Covered
* **Web Scraping / Data Ingestion:** Reading data directly from single and multiple web links using Python.
* **Data Transformation:** Renaming column names to standardize datasets.
* **Data Structuring:** Storing and organizing all collected data into a unified **Master Dictionary**.

### 📁 Project Structure & Milestones
* **Files 1–3:** Individual data collection and cleaning scripts.
* **File 4:** The core compilation script that combines data from Files 1 to 3 to generate **5 distinct projects**.
